# 个人投资模拟器

本地运行的个人投资流程演练工具，规则来自 `../personal_investment_interview_plan_spec_2026-10-22.md`。所有订单和成交只写入本机 SQLite，不连接券商。

## 启动

需 Python 3.11+。依赖为 FastAPI、Uvicorn 和 Pydantic；本机已有环境可直接启动：

```powershell
cd D:\my_work\quant_sp\personal_investment_simulator
.\start.ps1
```

浏览器打开 <http://127.0.0.1:8765>。按 `Ctrl+C` 关闭。服务只监听本机回环地址。

## 历史回测（新版首页）

- `/` 是简化的历史回测页；`/trade` 保留原模拟交易；`/settings` 集中管理费用等固定参数。
- 选择 1～9 只标的，分别填写每次金额，选择一次性、每周、每月或自定义日期投入，并分别指定投入开始、停止及评估日期。停止投入后持仓继续计价；历史记录可重新打开或导出 JSON。
- 回测用 hithink-finance 远端历史接口：场内 ETF/股票取**不复权开收盘价**，场外基金取**单位净值**；另外读取公司行动和分红。请求号、实际覆盖区间与价格口径显示在结果页。首次取数较慢，历史数据缓存在 `runtime/history/`；勾选“重新获取历史数据”可强制刷新。
- 场内按开盘价加滑点、100 股/份整手买入并扣最低佣金；场外按当日单位净值和外扣申购费计算份额。未够一手的预算按标的累计，够一手后在下一投入日尝试买入，留存现金计入总资产。现金分红按支付日（股票因接口缺支付日按除权日）入账，可在设置中选到帐再投资。最终保留现金、费用、逐笔交易、累计投入、组合市值、简单收益、XIRR、时间加权收益和最大回撤。
- 所有选中标的使用共同最新完整数据日，今日可能仍在形成的日线排除。日期早于任一标的的数据覆盖时明确报错；当前基金净值接口通常只覆盖约五年，不能把缺失的 2016 年基金数据填补为真实收益。
- **历史回测与 `/trade` 的 SQLite 现金及订单完全分离**：回测结果在 `runtime/backtests.sqlite3`，不会产生模拟交易订单或实际券商委托。
- 历史限购、暂停申购、ETF 实时 IOPV/溢价、场外真实确认日、赎回费及税费等没有逐日完整数据，未追溯纳入。股票分红的支付日缺失会影响现金再投资时点。回测可用于比较策略，不能当成当时必然可成交的交易记录。

可选手动启动：

```powershell
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8765
```

## 首次演练

1. 首次余额为 ¥0；点击“记入模拟账户”模拟投入 ¥3,000。
2. “本期预算路由预览”按当前账户、平台核验状态、额度、IOPV、成本及仓位上限计算；这只是预算建议，不会自动下单。
3. “刷新行情”从已配置的 hithink-finance CLI 请求股票和 513800 快照。上游失败时保留旧值并标为过期。
4. 快照早于当前 60 秒时不能直接下单。输入券商当前价格和时间；513800 还必须输入同一时点 IOPV。
5. 查看佣金成本和交易后持仓预检。ETF 100 份最低佣金 ¥5 的成本率会被算出，超过 0.5% 时阻断。
6. 标普基金和短债基金要先在“设置”页核验渠道开放状态、限额和折后费率；否则不能提交。
7. 场内订单提交后，在订单表点击“模拟成交”；场外申购进入待确认，依据平台确认记录填写确认净值、日期及凭据。
8. 撤单会释放冻结金额；所有状态和现金流水留在本机数据库。

## 数据与使用限制

- 初始行情来自 `../investment_assist_2026-10-27/` 保存文件，页面明确展示来源、请求号和观测时间。它们是历史快照，不是当前盘口。
- 513800 行情接口未返回 IOPV；程序不会推算或伪造 IOPV。
- 017641 每日 ¥10 和档案折后申购费率、012692 档案折后申购费率是研究来源的候选值；实际申购条件必须按本人销售平台核对后标记。
- 基金确认使用你录入的确认净值与依据。档案中没有净值日期的单位净值只作说明，不能用于确认。
- 五家跟踪股票没有买入批准；模拟器会阻断新增股票买入。回撤和仓位仅按 Spec 的预设闸门执行。
- 场内成交采用明示的假设：限价满足后，按刷新到的参考价记为模拟成交。不模拟排队和部分成交，不代表实际交易所撮合。
- 默认最低佣金 ¥5、佣金率 0.03% 为可编辑演练参数。本人平台费率、税费需自行核对；股票卖出税费未核验前阻断卖出模拟。
- 交易 SQLite 位于 `runtime/simulator.sqlite3`，回测 SQLite 位于 `runtime/backtests.sqlite3`。备份时关闭服务后复制；本地数据不要放入公开共享目录。
