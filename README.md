# 个人投资模拟器

本地运行的个人投资流程演练工具，规则来自 `../personal_investment_interview_plan_spec_2026-10-22.md`。所有订单和成交只写入本机 SQLite，不连接券商。

## 启动

需 Python 3.11+。依赖为 FastAPI、Uvicorn 和 Pydantic；本机已有环境可直接启动：

```powershell
cd D:\my_work\quant_sp\personal_investment_simulator
.\start.ps1
```

浏览器打开 <http://127.0.0.1:8765>。按 `Ctrl+C` 关闭。服务只监听本机回环地址。

## 历史回测（新版首页）

- `/` 是简化的历史回测页；`/trade` 保留原模拟交易；`/settings` 集中管理费用等固定参数。
- 选择标的、分别填写每次金额，选择每个可用交易/净值日、每周、每两周、每月、每季度、每半年、每年、一次性或自定义日期投入。周频可选周一至周五；月及更长周期可选每期第 1～28 日或本期最后一个可用日。停止投入后持仓继续计价；历史记录可重新打开或导出 JSON。
- 可在回测页输入 6 位 A 股代码（也可附 `.SH`、`.SZ`、`.BJ`），由 Hithink 标的目录精确校验名称和市场。校验通过的自选股票加入回测列表；首次运行会按所选区间拉取历史日线和公司行动，结果展示来源、请求号、记录覆盖和未复权价格口径。自选代码只保存在被 Git 忽略的 `runtime/backtest_stocks.json`，不会进入 `/trade` 模拟账户或订单池。
- 回测用 hithink-finance 远端历史接口：场内 ETF/股票取**不复权开收盘价**，场外基金取**单位净值**；另外读取公司行动和分红。请求号、实际覆盖区间与价格口径显示在结果页。首次取数较慢，历史数据缓存在 `runtime/history/`；勾选“重新获取历史数据”可强制刷新。
- 场内按开盘价加滑点、100 股/份整手买入并扣最低佣金；场外按当日单位净值和外扣申购费计算份额。未够一手的预算按标的累计，够一手后在下一投入日尝试买入，留存现金计入总资产。现金分红按支付日（股票因接口缺支付日按除权日）入账，可在设置中选到帐再投资。最终保留现金、费用、逐笔交易、累计投入、组合市值、简单收益、XIRR、时间加权收益和最大回撤。
- 所有选中标的使用共同最新完整数据日，今日可能仍在形成的日线排除。日期早于任一标的的数据覆盖时明确报错；当前基金净值接口通常只覆盖约五年，不能把缺失的 2016 年基金数据填补为真实收益。
- **历史回测与 `/trade` 的 SQLite 现金及订单完全分离**：回测结果在 `runtime/backtests.sqlite3`，不会产生模拟交易订单或实际券商委托。
- 历史限购、暂停申购、ETF 实时 IOPV/溢价、场外真实确认日、赎回费及税费等没有逐日完整数据，未追溯纳入。股票分红的支付日缺失会影响现金再投资时点。回测可用于比较策略，不能当成当时必然可成交的交易记录。

## 股票因子研究与回测

- `/research` 提供25家研究池的财报、PE/PB/PS/PCF、DuPont、质量/成长/估值/风险因子和组合回测页面。研究池由此前16家公司与9家电网、算力和软件候选公司组成；不改变模拟交易标的或研究批准状态。
- 每次运行可选择起止日、固定资金、每月投入金额和组合持股数。比较等权研究池、因子筛选前N名；有合格点时训练面板时，还可比较 Ridge/LightGBM。股票按下一可用交易日开盘、100股整手调仓；定投资金在月初先填目标低配仓位，完整卖买平衡只在季度调仓执行。
- 利润质量页显示经营现金/净利润、应计比率；当前Hithink历史接口未返回扣非利润、政府补助、投资收益、公允价值变动和股份支付的逐期拆分，因此这些字段留空并标为待补，不会把它们默认为零或主营利润。
- Hithink Finance 提供最多十年的季度财报、未复权日线、公司行动及沪深300指数行情。后台分年度拉取并在 `runtime/research/raw/` 缓存。研究运行、输出和导出单独保存在 `runtime/research/research.sqlite3` 及 `runtime/research/exports/`；和模拟账户/原回测账本分离。
- 报告保留每家公司的接口请求号、日期覆盖和财报披露时间，并可展开查看最近16期因子历史或下载因子历史CSV。财报按披露日后一天进入信号；TTM需要四个连续季度，收入和利润还会提供TTM同比及三年CAGR。动态财报与公司行动缓存每日更新。历史财报更正版本无法回溯，因此标为近似点时。历史PE/PB/PS/PCF用披露财报、股本和价格估算；当前估值快照另列PE/PB/PS/PCF及请求号，不混入历史回测。金融股由于缺少NPL、拨备、资本充足率、净息差、NBV等必要数据会显示“需补数据”，不会误用工业企业的FCF模型。
- 组合计价用未复权日线和披露分红/送转事件，计入模拟佣金、卖出印花税、滑点和按持仓批次估算的股息红利税；波动与回撤因子也会按现金分红/送转构造总回报序列。交易费率和除权处理是假设，报告会披露。沪深300接口基准为价格指数，不含成分股分红，页面不会称为全收益指数。25股固定研究池本身有幸存者偏差，不能单独据此证明策略可投资。
- 机器学习依赖可选。若要启用 Ridge/LightGBM，安装 `requirements-research-ml.txt` 并把经核验的历史CSI300点时训练面板放入 `runtime/research/csi300_pit_training.csv`。格式和防止未来成分泄漏的约束见 `docs/CSI300_TRAINING_PANEL.md`。没有历史成分和已成熟标签时，系统会说明ML未运行，不以当前成分股替代。
- 设计与评分口径见 `docs/STOCK_RESEARCH_SPEC.md`。

## 政策事件研究

- `/policy` 提供政策事件目录、公司关联证据登记、历史事件窗口研究和时点政策暴露。页面可从回测、模拟交易和股票研究导航打开。
- 导入 `policy_event_research` 的 9 条政策事件及 65 家公司研究池。公司政策关联需要人工填写业务依据、证据链接和证据可用日期；复核通过后才进入研究。起始数据库没有公司关联，因此不会预填政策利好股票。
- 事件研究通过 Hithink 同一历史行情接口取得股票和沪深300数据，用市场模型比较 `[-20,-2]`、`[-1,1]`、`[0,5]`、`[0,20]`、`[0,60]` 窗口，并保存请求号、输入快照、BH 多重检验 q 值和研究历史。
- 政策暴露分数只描述有证据的支持/限制暴露，缺少证据显示为“未知”，不填作零。当前结果不进入因子评分、组合回测、模拟账户或下单流程；政策预测层保持阻断，直到独立样本外验证完成。
- 事件研究使用未复权价格收益且不含分红；拆股、送转、除权除息会影响个别窗口。结果描述历史相关性，不证明因果关系或未来收益。
- 政策数据库单独存放在 `runtime/research/policy.sqlite3`。实施说明见 [docs/POLICY_RESEARCH_INTEGRATION.md](docs/POLICY_RESEARCH_INTEGRATION.md)。

### 2016 年起的 050025 定投示例

首页另有单基金长期定投卡片，默认 2016-01 开始、每月 1 日计划投入 ¥3,000、申购费率 0.12%、分红再投资。可编辑开始/停投/评估日期、每次金额、频率、周几或期内日期、费率及分红方式。结果给出累计投入、期末总值、盈亏、累计收益率、资金加权 XIRR，并可下载逐笔 CSV 或 JSON。

长历史净值与份额拆分使用 AKShare 的成立以来历史接口，分红记录使用 Hithink 基金分红接口；运行需要相应数据服务可访问。首末日期、数据源和归一化快照摘要随结果保存，2016 覆盖不足、冲突重复记录或远端不可用时显示错误，不回退成近五年结果。模拟假定每月都能申购，历史限购/暂停申购未还原；0.12%是统一模拟费率，不是历史费率复刻。分红再投资使用披露再投资日；若无该日则使用支付日，再顺延至有净值的日期。

2026-10-27 实际核验样例：2016-01 至 2026-10 每月 ¥3,000，130 期累计投入 ¥390,000；截至 2026-10-26 期末总值 ¥811,058.93，累计收益率 107.96%，XIRR 12.92%。本地历史缓存的 AKShare 3,406 条记录覆盖 2012-06-14 至 2026-10-26；与 Hithink 重叠的 1,210 个日期净值完全相同，另有 2 条 Hithink 记录在 AKShare 日期集合中未匹配。两渠道一致是交叉核对，不是独立审计证明。该样例按 0.12% 统一申购费率计算，并假定每月均可申购。

可选手动启动：

```powershell
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8765
```

## 首次演练

1. 首次余额为 ¥0；点击“记入模拟账户”模拟投入 ¥3,000。
2. “本期预算路由预览”按当前账户、平台核验状态、额度、IOPV、成本及仓位上限计算；这只是预算建议，不会自动下单。
3. “刷新行情”从已配置的 hithink-finance CLI 请求股票和 513800 快照。上游失败时保留旧值并标为过期。
4. 快照早于当前 60 秒时不能直接下单。输入券商当前价格和时间；513800 还必须输入同一时点 IOPV。
5. 查看佣金成本和交易后持仓预检。ETF 100 份最低佣金 ¥5 的成本率会被算出，超过 0.5% 时阻断。
6. 标普基金和短债基金要先在“设置”页核验渠道开放状态、限额和折后费率；否则不能提交。
7. 场内订单提交后，在订单表点击“模拟成交”；场外申购进入待确认，依据平台确认记录填写确认净值、日期及凭据。
8. 撤单会释放冻结金额；所有状态和现金流水留在本机数据库。

## 数据与使用限制

- 初始行情来自 `../investment_assist_2026-10-27/` 保存文件，页面明确展示来源、请求号和观测时间。它们是历史快照，不是当前盘口。
- 513800 行情接口未返回 IOPV；程序不会推算或伪造 IOPV。
- 017641 每日 ¥10 和档案折后申购费率、012692 档案折后申购费率是研究来源的候选值；实际申购条件必须按本人销售平台核对后标记。
- 基金确认使用你录入的确认净值与依据。档案中没有净值日期的单位净值只作说明，不能用于确认。
- 五家跟踪股票没有买入批准；模拟器会阻断新增股票买入。回撤和仓位仅按 Spec 的预设闸门执行。
- 场内成交采用明示的假设：限价满足后，按刷新到的参考价记为模拟成交。不模拟排队和部分成交，不代表实际交易所撮合。
- 默认最低佣金 ¥5、佣金率 0.03% 为可编辑演练参数。本人平台费率、税费需自行核对；股票卖出税费未核验前阻断卖出模拟。
- 交易 SQLite 位于 `runtime/simulator.sqlite3`，回测 SQLite 位于 `runtime/backtests.sqlite3`。备份时关闭服务后复制；本地数据不要放入公开共享目录。
